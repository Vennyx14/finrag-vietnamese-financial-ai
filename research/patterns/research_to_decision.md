# Pattern — Research-to-Decision Workflow

For every external technique:

1. **Source:** exact paper/repository and pinned version.
2. **Claim:** what the source explicitly supports.
3. **Observation:** what we directly confirmed in source code.
4. **Gap:** which measured FinRAG failure this might address.
5. **Decision:** apply, experiment later, reference only, or reject.
6. **Preconditions:** data, schema, licensing, hardware and baseline.
7. **Experiment:** minimal test with fixed cases and acceptance criteria.
8. **Result:** run status, environment, metrics and limitations.
9. **Follow-up:** adopt, revise or revert.

Do not turn an idea into an architecture commitment until the experiment supports it.
